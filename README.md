# Tom Rider

A MakeCode Arcade game, playable [in the browser](https://fdreger.github.io/tom-raider/), but also on all sorts of
[fun embedded devices](https://arcade.makecode.com/arcade-devices).

The game was made for [GBA Jam 2026](https://itch.io/jam/gbajam26) and is available on [itch.io](https://fdreger.itch.io/tom-rider).
